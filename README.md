# פנקס — פנקס חובות דיגיטלי למכולות

אפליקציה למוכר (PWA) שמחליפה את פנקס ה"הקפה" מהנייר.
כל חוב או תשלום נשמר רק אחרי שהלקוח מקיש קוד אישי בן 4 ספרות על המסך של המוכר. כך נגמרים הוויכוחים של "לא קניתי את זה".

הממשק בעברית בלבד, מימין לשמאל, בשקלים (₪).

## מה יש באפליקציה

- **רישום חוב או תשלום בתוך פחות מ-7 שניות:** חיפוש לקוח ← סכום ← קוד הלקוח. האישור נשלח לבד בספרה הרביעית.
- **אישור לקוח על כל פעולה:** שום עסקה לא נשמרת בלי הקוד של הלקוח או אישור של בעל העסק. גם תשלום חלקי צריך קוד.
- **ביטול עסקה:** עובד יכול לבטל תוך 15 דקות עם הקוד של הלקוח. אחרי זה רק בעל העסק יכול. העסקה מסומנת "בוטל" ולא נמחקת.
- **הגנה על הקוד:** אחרי 5 קודים שגויים הלקוח ננעל ל-5 דקות. הקודים והסיסמאות נשמרים מוצפנים (argon2) ולא יוצאים מהשרת.
- **תקרת אשראי לכל לקוח:** חוב מעל התקרה דורש אישור של בעל העסק.
- **כמה קופות במקביל:** היתרות מתעדכנות בכל המכשירים תוך כמה שניות.
- **הרשאות:** בעל עסק ועובד. בעל העסק מנהל לקוחות ועובדים, מאפס קודים ורואה יומן פעולות מלא.
- **יומן פעולות:** כל אישור בעלים, ביטול, איפוס קוד וקוד שגוי נרשמים.

## טכנולוגיות

Next.js 15 · React 19 · TypeScript · Tailwind CSS 4 · PostgreSQL · Drizzle ORM · TanStack Query · Vitest · Playwright

## הרצה מקומית

צריך Node.js 20 ומעלה. אין צורך ב-Docker, כי מסד הנתונים המקומי רץ דרך npm.

```bash
npm install
cp .env.example .env
npm run db:start      # מסד נתונים מקומי על פורט 5433. להשאיר פתוח בטרמינל נפרד
npm run db:migrate
npm run seed          # חנות לדוגמה
npm run dev           # http://localhost:3000
```

### כניסה לחנות לדוגמה

| תפקיד | שם משתמש | סיסמה |
|---|---|---|
| בעל עסק | `owner` | `owner1234` |
| עובד | `employee` | `employee1234` |

- קוד בעלים (לאישור על מכשיר של עובד): `9999`
- קוד של כל הלקוחות לדוגמה: `1234`

אלה נתוני דמו בלבד. בחנות אמיתית צריך ליצור משתמשים וקודים חדשים.

## בדיקות

```bash
npm test              # בדיקות יחידה לכללי העסקאות
npm run test:e2e      # בדיקות בדפדפן (Google Chrome). דורש ש-db:start ירוץ
npm run typecheck
```

## העלאה לשרת

1. מגדירים `DATABASE_URL` לכל PostgreSQL בגרסה 14 ומעלה.
2. מריצים:

```bash
npm run db:migrate
npm run build
npm start
```

3. בכניסה הראשונה האפליקציה עוברת למסך `/setup`, שבו יוצרים את החנות ואת בעל העסק.

## עוד לא נבנה

- מנוי פרימיום: תזכורות SMS חודשיות וקישור לתשלום מרחוק (יש רק כרטיס דמה במסך הניהול).
- עבודה בלי אינטרנט.
- הגבלת ניסיונות הכניסה נשמרת בזיכרון. לפני שמריצים כמה שרתים במקביל צריך להעביר אותה ל-Redis או למסד הנתונים.

## מבנה הקוד

- `src/server/ledger.ts` — כל הלוגיקה שמשנה יתרות (עסקאות, ביטולים, לקוחות, איפוס קוד)
- `app/api/` — ה-API
- `app/(app)/` — המסכים: קופה, לקוח, לקוח חדש, עסקאות אחרונות, ניהול
- `src/components/PinOverlay.tsx` — מסך הקוד שהלקוח רואה
- `tests/` — בדיקות יחידה ובדיקות דפדפן
